```text
Работай только с локальными файлами. Осмотри папку соревнования. Найди train/test/sample_submission, target column, id column, подсказки про метрику и тип задачи. Составь короткий список того, что нужно проверить перед моделированием. Интернет не использовать.
```

## Baseline

```text
Построй самый простой воспроизводимый baseline для этого датасета. Используй локальные файлы в текущей папке. Сохрани OOF predictions, validation score, feature importance если возможно, и submission.csv. Код должен быть простым и легко проверяемым.
```

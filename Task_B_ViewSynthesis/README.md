# Задача B — Синтез новых ракурсов по нескольким камерам

## Задача

Восстановить изображение с одной камеры беспилотного автомобиля в **промежуточный момент времени**,
имея соседние кадры и плотное LiDAR-облако точек. Качество оценивается по **PSNR**
относительно ground-truth кадра.

- 6 камер: `front, left_fwd, left_bwd, right_fwd, right_bwd, rear`
- Вход: все камеры в моменты **t0** и **t1** (2 с разницы), целевая камера + целевое время
  между ними, внутренние/внешние параметры камер и ~10M точек LiDAR в мировых координатах.
- Выход: изображение целевой камеры в целевой момент времени (кадр, который никогда не был записан).

## Решение

Смешивание трёх независимых оценок целевого кадра, взвешенных по confidence:

1. **Временная интерполяция оптическим потоком** — DIS-поток в обе стороны между t0/t1, варпинг
   к целевому моменту, blend с учётом окклюзий.
2. **RIFE** — глубокая интерполяция кадров, подмешивается с весом (`rife_mix=0.42`).
3. **LiDAR image-based rendering** — проекция LiDAR-облака в целевой ракурс для получения
   плотной карты глубины, обратная проекция каждого пикселя в 3D, репроекция в исходную камеру
   и сэмплирование цвета (`lidar_mix=0.30`).

Результат записывается как near-lossless JPEG (метрика — попиксельный PSNR).

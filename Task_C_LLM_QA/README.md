# Задача C — Ответы на школьные вопросы с помощью LLM

## Задача

Отвечать на школьные вопросы (на русском языке) корректно, кратко и по существу — полностью
офлайн в Docker-контейнере с ограниченным бюджетом вычислений и времени.

## Решение

Небольшая модель **Qwen3** (~0.6B параметров), обслуживаемая через **vLLM**, плюс гибридная маршрутизация:

```
вопрос ─┬─ похоже на чистую арифметику? ─ да ─▶ точный вычислитель (Fraction math)
        └─ нет ────────────────────────────▶ vLLM (Qwen3, greedy decoding)
```

- **Арифметический путь** (`try_arithmetic`): консервативно определяет чисто вычислительные задачи
  и решает их точно с помощью `fractions.Fraction` через белый список AST-узлов (никогда `eval()`).
  Маленькие LLM ошибаются в арифметике — этот путь делает такие вопросы всегда правильными.
- **LLM-путь**: greedy decoding (`temperature=0.0`), `max_tokens=192`, короткий `max_model_len`
  для пропускной способности. Системный промпт требует коротких и точных ответов; из вывода
  убираются блоки `<think>` и маркеры чат-шаблона.

## Веса модели

Дообученные веса Qwen3 (~1.4 ГБ) хранятся на Hugging Face, а не в этом репозитории:

**https://huggingface.co/roreternity/yandex_mlcup_taskc**

Скачайте их в `task_c_solution/weights/` перед запуском решения.
